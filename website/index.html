Export your entire journal database to a JSON file. Restore anytime on any device running the app.

under the surface

Clean architecture,
modular features.

DAYMARK separates data, domain, and presentation layers across each feature module. Business logic never touches the UI directly. The database, the summary engine, and the export pipeline are each isolated behind abstract contracts.

Feature-driven modules Journal, Contribution, Summary, Settings, Dashboard, and Navigation are self-contained feature directories.
Pluggable summary engine An abstract contract lets you swap between Google Gemini and the local heuristic engine without changing any screen code.
Riverpod state management Reactive providers manage journal lists, streak calculations, settings, and async data loading with automatic disposal.
